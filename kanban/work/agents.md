# Agents

Scope boundary: `kanban/work`

Session contract:

- Start with `kan start --json`.
- Use `kan agent claim --scope kanban/work` or claim by task when parallel edits are likely.
- Keep claims narrow and short-lived.
- If overlap risk appears, pause and re-claim with narrower scope.
