# Agents

Scope boundary: `kanban/roadmap`

Session contract:

- Start with `kan start --json`.
- Use `kan agent claim --scope kanban/roadmap` or claim by task when parallel edits are likely.
- Keep claims narrow and short-lived.
- If overlap risk appears, pause and re-claim with narrower scope.
